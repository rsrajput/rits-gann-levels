# Rits Gann Levels

A simple, lightweight Rust command-line tool to calculate Gann price
levels for any stock using its current market price. No stock ticker or
symbol is required.

The program calculates five levels below and five levels above the
integer part of the current price's square root. It then adjusts each
calculated price level so that every displayed level is odd.

## Features

-   Accepts any positive stock price as input.
-   Calculates the square root of the entered price.
-   Truncates the square root to its integer part, ignoring decimals.
-   Calculates five Gann levels above and five below the truncated
    square root.
-   Adds 1 to any even calculated price level so that all displayed
    levels are odd.
-   Displays the base level for reference.
-   Runs locally in the terminal.
-   Uses only the Rust standard library; no third-party crates are
    required.

## How Gann Levels Are Calculated

Let:

-   `P` = current stock price
-   `S` = integer part of the square root of `P`
-   `n` = offset from 1 to 5

### 1. Truncate the square root

Calculate:

`S = floor(sqrt(P))`

For example, if the entered price is `2600`:

-   `sqrt(2600) ≈ 50.9902`
-   Truncated square root: `S = 50`

### 2. Calculate the raw levels

For each offset `n` from 1 to 5:

**Lower levels**

`Lower(n) = (S - n)²`

**Upper levels**

`Upper(n) = (S + n)²`

The base reference level is:

`Base = S²`

For an input price of `2500`, the truncated square root is `50`,
producing raw root levels from `45` through `55`.

  Direction     Root level   Raw price
  ----------- ------------ -----------
  Below                 45        2025
  Below                 46        2116
  Below                 47        2209
  Below                 48        2304
  Below                 49        2401
  Base                  50        2500
  Above                 51        2601
  Above                 52        2704
  Above                 53        2809
  Above                 54        2916
  Above                 55        3025

### 3. Adjust every price level to an odd number

After squaring each root level, the program applies this rule:

-   If the raw price is odd, keep it unchanged.
-   If the raw price is even, add 1.

Examples:

    Raw price   Displayed level
  ----------- -----------------
         2025              2025
         2116              2117
         2209              2209
         2304              2305
         2401              2401
         2500              2501
         2601              2601
         2704              2705
         2809              2809
         2916              2917
         3025              3025

**Important:** The odd-number adjustment is applied to the final price
levels, not to the square-root values. Therefore, the displayed base
level may differ from the square of the truncated square root.

## Requirements

-   Rust toolchain
-   Cargo

## Project Structure

``` text
rits-gann-levels/
├── Cargo.toml
├── Cargo.lock
├── LICENSE
├── README.md
└── src/
    └── main.rs
```

`Cargo.lock` is generated by Cargo. For a binary application, commit it
to Git.

## Build and Run

### Run in development mode

``` bash
cargo run
```

### Build the optimized release executable

``` bash
cargo build --release
```

The executable will be created at:

``` text
target/release/rits-gann-levels
```

### Run the release executable

``` bash
./target/release/rits-gann-levels
```

Enter the current stock price when prompted.

## Daily Workflow

If the source code has not changed, there is no need to rebuild every
day:

``` bash
cd ~/Documents/rits-gann-levels
./target/release/rits-gann-levels
```

After changing `src/main.rs`, format, check, rebuild, and run:

``` bash
cd ~/Documents/rits-gann-levels
cargo fmt
cargo check
cargo build --release
./target/release/rits-gann-levels
```

## GitHub Setup and Push

Create an empty repository named `rits-gann-levels` on GitHub. If you
are pushing this existing local repository, leave the GitHub repository
empty rather than initializing it with another README or license.

### First push

If Git has not yet been initialized locally:

``` bash
cd ~/Documents/rits-gann-levels
git init
git add Cargo.toml Cargo.lock src/main.rs README.md LICENSE
git commit -m "Initial release of Rits Gann Levels"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/rits-gann-levels.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username.
